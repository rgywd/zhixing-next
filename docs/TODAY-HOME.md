# 今天：首页与手机信息

当前源码按首页参考图重构“今天”：位置天气栏、今日节律建议、下一项日程、财务和健康速览、固定常用与最近动态。顶部位置天气栏在系统安全区下额外留出间距，文字、图标与日期在栏内垂直居中，窄屏可换行。首页数值取实际服务记录，未设置预算或未读取记录时保持未知；不从漏记计算饮食达标率，也不预设步数目标。

此首页更新纳入 [0.2.2 发布](RELEASE-0.2.2.md)，既有 v0.2.1 正式 APK 不包含此页。同签名首页预览可直接覆盖安装 0.2.2，保留原连接、偏好与草稿，无需卸载。

今日信息弹层的标题行刷新图标及操作精简属于 0.2.2 之后的界面改动，由本次预览包或后续正式版提供；既有 v0.2.2 Release 附件保持不变。

## 从首页使用

- 点击顶端位置天气栏打开“今日信息”。位置天气与手机日历的刷新图标放在各自标题行右侧，没有背景；首次点击按需启用或请求权限，之后刷新已有信息，不在首次启动时连续弹权限。读取中禁用重复操作，错误与系统设置恢复仍就近显示。
- 位置天气启用后，首页在前台更新区域和天气；位置由系统 GPS、Wi-Fi、基站融合，允许大概位置，使用系统已有的网络辅助配置。面板不再提供增强辅助、停止天气或断开日历操作。不扫描 SSID/BSSID，不申请附近 Wi-Fi、后台定位或定位前台服务权限。
- 天气通过 HTTPS 向 Open-Meteo 查询，只发送保留两位小数的经纬度，不带知行令牌。天气为模型当前天气数据，保留数据时间，不再单列天气来源操作行；隐私说明中的 Open-Meteo 保留为内联链接，条款见本文末尾。无有效定位时保持未知；同一地区的天气更新失败时保留仍在有效时间内的上次天气，并显示更新失败提示。反向地理编码失败只显示“当前位置”。
- 日历只读取并展示今天的日程，过滤取消／本人拒绝的活动，展示正在进行或下一项定时日程，再考虑全天活动。点击打开系统日历查看，不自动创建或修改日程。
- 时间和日期跟随手机时钟及当前时区，无需额外系统授权。跨日会重新读取当天记录与日程；已启用的定位天气按 15 分钟节流，日历按 1 分钟节流。
- “开始”把输入与已读取的今日信息追加到原主 Agent 草稿，可修改后自行发送；不自动创建会话或提交消息，也不覆盖原草稿。分享的地点是地区名称，不附精确坐标。
- 财务和健康速览卡进入生活子页，返回生活；记账可从财务页的“记一笔收支”进入财务 AI，手工草稿可从财务页底部“手动补记”恢复。速览卡下方已移除“记一笔开销”和“梳理乱序思路”两个快捷按钮。

## 授权与本机状态

Android 只申请使用时定位和 `READ_CALENDAR`；`WRITE_CALENDAR` 继续在生成 manifest 中阻止。SDK 57 的日历权限函数会同时要求读写，因此 Android 采用 React Native 的只读权限请求，再使用新的 Calendar 读取 API。原设置页的系统日历编辑器继续使用显式 legacy 入口，无需本 App 获得写权限。

iOS 配置日历 full access 的读取用途说明（系统权限粒度），代码只调用读取；本次原生验收目标仍是 Android 模拟器，iOS 另列实际验证边界。

自动读取的当日坐标、天气和日程，以及启用偏好保存在本机；冷启动先确认开关与当前系统权限，再恢复当日缓存，后台重新读取。天气仍按观测时间校验，过期天气不作为当前天气，昨日的日程不作为今日安排。用户选择带入聊天的概况按原草稿机制保存在本机。离开首页或进入后台取消定位／天气请求并忽略迟到结果，权限撤回后清除相应信息；可在系统设置管理权限。不会自动上传这些资料；用户从首页开始后，今日概况进入可编辑的聊天草稿，只有用户自行发送才分享给服务。系统定位及反向地理编码由操作系统处理。

读取开关失败时提供重试，不用默认值覆盖原设置；权限拒绝不反复自动申请，可手动重试或打开系统设置。时间与天气没有单独的系统“权限”；天气使用网络及用户选择的位置。

## 实现与验证

- `TodayHomeView.tsx` 负责参考图布局，复用共享主题尺度；`OverviewPanels.HomePanel` 保留常用、最近和资源操作。
- `TodayHomePanel.tsx` 组合手机与服务数据、权限操作和可编辑草稿交接。
- `useTodayDeviceContext.ts` 管理本机会话状态与取消，`todayLocation.ts`／`todayCalendar.ts` 接入原生能力，`todayWeather.ts` 校验天气数据，`todayHomeLogic.ts` 负责真实摘要和时间边界。
- `useTodayServices.ts` 按手机当地日期读取财务月度及健康当日汇总，换连接／跨日／卸载后忽略旧请求，不把昨天的健康记录当成今天。

PR #25 的合入前预览已通过移动端门禁、两平台 JS bundle、权限 manifest 检查及 Android 16 ARM64 模拟器原生验收，覆盖授权／拒绝、定位取消、只读日历、主草稿追加，以及明暗主题、320dp 和键盘布局。验收使用明确的模拟定位与临时本机日历记录，并实际请求到 Open-Meteo 天气；不证明实体设备 GPS 或 Wi-Fi 信号质量。系统日历打开意图已发出，但模拟器日历查看器未显示该临时本机事件详情，首页读取展示已通过。

上述是首页预览验收；0.2.2 正式 APK 的构建、覆盖安装与启动结果以 [Release 验收附件](https://github.com/rgywd/zhixing-next/releases/download/v0.2.2/ACCEPTANCE.md)为准。实体 Android 手机与原生 iOS 尚未验收；个人截图、连接信息和临时日历内容不发布。
