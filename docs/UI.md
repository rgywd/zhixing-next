# 共享 UI

聊天输入栏的上下文圆环与模型、思考深度、权限图标相邻；每轮回复末尾提供统计与 Token 读数。三种详情均为页面内锚定 box，遵循日夜主题，点击外部或返回收起。数据与压缩行为见 [DSH 上下文与会话统计](DSH-CONTEXT-STATS.md)。

私密变量采用对话内填写卡，复用共享卡片、输入与按钮尺度，支持多项和变量名编辑。值以密码形式输入，启用原生屏幕隐私保护后才可填写；同名替换显式勾选，取消和失败留在卡片内处理。填写状态与普通聊天草稿完全分离，切到后台清空未提交值，见[私密变量](PRIVATE-VARIABLES.md)。

2026-10-29 对话重做：DSH 用户消息的编辑直接回填同一个输入框，显示“编辑消息”和取消；普通草稿独立保留。助手消息直接重答；回复下方箭头切换实际版本。工具过程默认折叠为动作摘要，展开时保持阅读位置；文件内容、修改前后和真实错误优先呈现，原始参数／XML／路径收在“技术详情”。文件交付消费 DSH 原生 `present`，显示名称、描述、预览与分享，不再要求用户手动发布。产品验收见[真实对话重做](AI-CHAT-REDESIGN-2026-10-29.md)。

客户端使用日夜两套主题，颜色、字阶、间距与尺度由 [`src/theme.ts`](../src/theme.ts) 维护。
白天以白色底面、朱红主操作、金色选中与思考状态为主；搜索、资料等功能少量使用冷蓝。
对话使用中性底色与明确的文字层级，发送按钮使用 ink/onInk；夜间采用近黑底面与炭灰浮层，主操作使用柔白，暗金用于选中与思考，卡其用于辅助图标。
绿色只保留成功等状态含义，模型品牌图标保留原色。夜间隐藏为浅色背景绘制的装饰插画。

[`ThemeProvider`](../src/ThemeProvider.tsx) 统一管理“跟随系统 / 白天 / 夜间”，默认跟随系统，偏好保存在本机。
聊天菜单用同一个 box 的子列表选择主题；其他页头外观图标与设置首页继续打开底部选择器。它们共享本机偏好，未连接服务也可调整；切换不重挂载页面，不清空草稿。
Expo 使用 `userInterfaceStyle: automatic` 与 `expo-system-ui`，状态栏、系统根背景和原生外观随主题变化。
新增原生依赖需要重建 development build；Expo Go 的运行验收不能替代独立原生包验收。

页面在组件内通过 `useUi()` 获取 `s` 和 `colors`，专有样式使用 `useThemedStyles(createStyles)`；
样式工厂接收 `ThemeColors`，禁止在模块顶层固定当前配色。底面使用 `surface` / `surfaceRaised`，
填充按钮分别使用 `primary` / `onPrimary`、`ink` / `onInk`，不能把白色同时当作背景与按钮文字。
共享组件由 [`src/ui.tsx`](../src/ui.tsx) 维护，同一种元素修改共享定义，不在各页面复制数值。

## 页面组合

- 手机顶层入口为首页、生活、知行、施工中、设置。首页、生活、施工中、设置使用 `PageScrollView tabs` 与 `PageHero`。`tabs` 负责浮动底栏留白，
  页头插画通过 `art` 和 `artStyle` 接入；插画位置等专有排版留在所属页面。
- 管理子页使用普通 `PageScrollView`、`PageHeading`，由外层提供 `BackLink`。子页不预留底栏空白。
- 密码管理是设置“工具箱”的本机子页，使用共享字段、按钮与分组样式；列表为虚拟列表，附加资料按需展开。为保证离开时锁定，由面板自己提供唯一返回入口并处理 Android 返回键，外层不重复放置 `BackLink`。锁定会卸载解锁界面，清除搜索、显示状态与输入中的主密码；秘密复制反馈不得包含值。
- 财务和健康是生活子页，隐藏底栏，页内返回与 Android 返回键回到生活；服务表单先返回服务页。原工作位置只展示“施工中”“功能待定”，不恢复旧工作操作。
- 财务和健康概览共用 `ServicePrimitives`：固定顶栏的返回、周期切换与外观，紧凑页头、圆角分区卡、大数字与双列指标。尺度由 `theme.ts` 的 `serviceLayout` 和原字阶统一提供；表单继续复用共享输入控件。进度与指标仅显示真实记录或预算推导值，未设置或尚未读取的数据明确标出。
- 新增收支遵循 AI-first：财务“记一笔收支”和空态直接打开财务 AI，不先弹表、不自动发送模板消息；已有会话、输入和附件继续保留。重复的对话录入入口合并，手动补记放在记录卡底部作为次要操作，预算与已有记录的纠正、退款、删除继续按需使用。
- 模型、思考、搜索等即时选择与创建项目等短表单使用 `BottomSheet`，保留当前页面背景。支持淡入遮罩、滑入／滑出、下拉手柄、点击遮罩和系统返回；尊重系统减少动态效果设置。文件浏览、任务记录、完整对话列表等长内容页仍使用 `SheetHeader`。
- 同一时刻只展示一个原生弹层。从底部面板打开文件预览时，先关闭并等待面板的关闭回调，再打开预览；预览关闭完成后才重新打开原列表。iOS 使用 `Modal` 的 `onDismiss`，Android 在关闭后的提交效果中通知，不用定时器猜测动画时长。
- 卡片使用 `s.card` 和 `CardHeader`；双列入口使用 `ServiceTile`，纵向入口使用 `ActionRow`。
  `ActionRow compact` 用于最近对话等较密的列表，末行传 `last` 去掉分隔线。窄屏时 `ServiceTile`
  自动变为单列，`PageHero` 隐藏装饰插画，为大字号文字保留整行宽度。
- 主要提交动作使用 `Button`，次要动作使用 `ActionLink`，单图标操作使用 `IconAction`。状态使用 `StatusPill`，入口图标可通过 `UiTone` 对应语义色。输入和空状态使用 `Field`、`Empty`。`Empty compact` 用于卡片内部；
  正文阅读使用 `s.text`，说明使用 `s.description`，辅助信息使用 `s.muted`。

```tsx
const { s } = useUi();

<PageScrollView tabs>
  <PageHero eyebrow="LIFE" title="生活" description="打理收支、饮食和体重。" />
  <View style={s.card}>
    <CardHeader icon="wallet-outline" title="财务" tone="gold" />
    <ActionLink icon="arrow-forward" tone="gold" onPress={onFinance}>预算与记录</ActionLink>
  </View>
</PageScrollView>
```

共享组件负责外观、触摸区域和无障碍语义，不请求数据或决定业务跳转。语义色只说明入口类型或状态，不表示未经验证的模型能力。页面传入文字与回调，
保留原有加载、错误和禁用条件。沉浸式聊天可以保留消息气泡和输入区的专有布局，通用文字与控件仍复用全局基础。

新增页面先选以上组合；只有插画、专有网格、消息等内容布局需要局部 `StyleSheet`。
通用的字号、卡片间距和图标底座不再另建一套。视觉修改除客户端门禁外，需检查主页面、代表性子页、
320dp 窄屏及返回路径，原生运行验收与 JS bundle 结果分别记录。

## 对话与选择器

- 欢迎页使用单一知行标识、主标题和四个轻量话题按钮；点击只追加草稿，不自动发送。页头显示助手身份及实际连接状态。
- 首次对话、主 Agent、财务与健康共用 `ConversationComposer`：上方全宽多行正文，下方是附件、真实模型、可用的思考／搜索、长文展开和发送／停止。对话标题在页头主行以较大粗体显示，次行显示“知行：模型名称”（子助手使用实际助手名称）；输入框只显示品牌图标。模型、思考深度、权限管理三个图标在同一横排紧邻，权限不单独靠右；选择器及无障碍名称保留模型全称，窄屏工具栏可横滑。不显示不支持的思考入口或虚假语音按钮。
- 编辑使用原输入框，保留上下文；取消恢复进入编辑前的普通草稿，发送后仍保留普通草稿。已提交但结果未确认时锁定修改，重试沿用同一请求。附件保留／移除与图片预览沿用原生附件。
- 尚未执行的消息通过共享 `QueuedMessages` 紧凑显示在输入框上方；多条队列在弹层查看。空队列不占空间，排队条参与布局，不遮挡正文。撤回／引导使用专用原子接口，不复用取消当前回复。
- 设置 → 对话设置保存本机主／子助手通用的默认发送方式；本条有内容的草稿可在输入框「+」→「发送方式」中改为“接着处理”或“补充当前回复”。默认值只影响新开始编辑的消息；补充目标在开始编辑时绑定，目标结束后需显式改为接着处理，不自动补到另一条回复。
- `ReplyContent` 与 `useReplyProcesses` 为每条回复保留有序正文、供应商思考和工具回执，主／财务／健康共用。运行中预览最近两步，思考可收起、预览或完整展开；完成默认收起，主动展开保持。历史和冷启动从持久投影恢复，流式与最终消息保持相同运行 key；SSE 不支持时兼容游标轮询。向上阅读暂停跟随，可悬浮返回最新。空草稿的发送按钮变为停止；复制、引用／修改到草稿、朗读与处理记录放在消息操作中，编辑不自动发送。Markdown 共用解析和语义块复用，代码和表格仅局部横向滚动；表格按内容分配列宽并提供复制。DSH 正文中的已交付文件链接打开同一个预览，未经交付的路径不能获得文件访问权限。没有思考数据时不生成占位思考。
- 真实 App 的主欢迎页及主／子 Agent 会话统一使用 `AgentChatHeader`，常驻侧栏、话题与助手／模型、新建和菜单；右上角菜单是页面内锚定按钮的紧凑 box，无原生 Modal、底部抽屉或暗色遮罩。菜单从上到下为当前对话名称（可改名）、分享、在聊天中查找、主题（当前实际白天／夜间）和红色删除。改名、主题和删除确认都在同一 box 内完成；点外部或系统返回收起。聊天内查找在页头下方展开，定位当前版本正文，搜索期间暂时隐藏输入框和回到最新浮标，关闭后恢复草稿。返回来源页面放在侧栏，固定操作仍在首页。子 Agent 页新建对话保持当前助手身份；同一套导航回归同时覆盖主 Agent、财务和健康，不能把子 Agent 的旧外观当作兼容要求。
- 会话输入框「+」提供“本对话文件”：底部面板只列出当前对话、当前所选版本中助手已交付的文件，新交付在前，并按同一交付路径去重（没有路径的附件按 DSH 附件 ID），再次交付同一文件时更新为最新卡片；文件名搜索中文原样、英文忽略大小写，读取中、无文件与无匹配分别提示。列表、预览和系统分享复用文件卡片与 DSH 交付数据，不读取其他对话、已切走版本、用户附件或未交付的工作区文件。打开面板不卸载对话，保留草稿与滚动位置；分享准备、失败与重试都在面板内可见，准备期间不能重复点击。
- 小图标保持可读的无障碍名称和至少 40 × 44dp 的触摸区域，当前模型名称在页头及选择器中显示。发送、重试、草稿锁定、图片附件和排队／引导的原有业务语义保持一致。
- 聊天「+」提供「照片」和「文件」两个入口。照片直接系统多选，返回输入框的持久草稿；96dp 纯图片缩略图横向排列，不显示名称、大小或底部移除行，右上角 44dp 叉号区域不能盖住图片中央。点图打开全屏预览，左右翻图；发送后的图片也不包成文件卡片。一次发送自动传图并提交同条消息，失败保留照片与文字，重试不重复传已收到的项。欢迎页、主知行、财务与健康共用。普通文件仍进入资料页。见[聊天照片](PHOTO-UPLOADS.md)。
- 权限管理复用底部选择器，提供“仅可查看”（眼睛）、“工作区内修改”（手掌）、“完全访问”（红色盾牌）。当前值和可选能力来自 DSH；未知或未连接时不伪装成任何已生效模式。切换等待宿主真实回执，失败留在面板内重试；欢迎页选择随草稿保存，首次建会话时应用。主聊天、财务、健康共用。具体审批与沙盒范围遵循 DSH 原生策略，既有审批卡继续负责批准和拒绝。
- `BrandIcon` 只负责显示品牌；来源记录在 `assets/brands/README.md`。未知模型使用通用芯片图标。图片和思考能力标签取服务端目录，不根据品牌猜测。
- `ModelPicker` 使用紧凑列表、搜索、供应商筛选和收藏；`ReasoningPicker` 仅显示服务端按当前模型 ID 匹配的选项；仅支持开关的模型显示“关闭 / 开启”，预算档位在说明中列出 token 上限；`SearchPicker` 默认展示开关和已配置服务，添加密钥表单按需展开。
- `MessageBody` 统一普通与财务对话中的 Markdown、表格、链接和可选择文字。用户消息使用右侧中性底色气泡，助手回复留足正文宽度，辅助动作使用图标。
- 设置和管理页优先使用分组列表、行尾操作；不要为每个选项创建一整张卡片和一排通栏按钮。空项目不重复展示图标、空状态和大按钮。

## 连接状态

[`NoticeProvider`](../src/Notice.tsx) 挂在安全区内，集中显示悬浮提示，不占页面布局空间，不拦截提示栏以外的触摸。`useNotice().show()` 支持普通、成功、警告、错误四种语义色、操作按钮及关闭；默认 4 秒后消失，`duration: null` 保留到调用 `dismiss(id)`。传相同 `id` 更新原提示和计时，较新的提示暂时覆盖旧提示，关闭后尚未结束的状态提示重新显示。页面卸载时应撤下自己创建的持续提示。

```tsx
const { show, dismiss } = useNotice();
show({ message: "已保存", tone: "success" });
show({ id: "upload", message: "正在上传", duration: null, dismissible: false });
// 上传结束
dismiss("upload");
```

`ConnectionStatusProvider` 聚合后台读取的状态：同一来源连续失败至少 3 次且持续至少 15 秒才显示一条自动重连提示；短暂失败静默。任一失败来源尚未恢复时保留提示，全部恢复后自动移除。401/403 立即提示检查连接凭证。
同步提示复用共享提示栏，提供重新连接和关闭；关闭后不因同一故障的后台轮询反复弹出，恢复或提示内容变化后再正常处理。执行服务离线及模型未配置也使用此悬浮层，不再单独占据页面行高。日夜主题与大字号随共享主题变化。

页面保留已加载内容和本地草稿；后台轮询的错误不能覆盖发送、批准、模型切换等用户操作的错误。用户操作失败仍立即显示，批准失败不移除待批准项。旧服务端没有批准列表（404）时不持续提示断线。

## 设置入口

底栏原“工具箱”改为两字“设置”，使用齿轮图标；侧栏只保留对话搜索和记忆。
设置首页参考旧版知行 RikkaHub 的 CardGroup 结构，通过 `SettingsGroup` 与 `ActionRow compact`
分为“通用”“工具箱”“模型与服务”“助手”“数据与连接”，通用分组保留日夜外观选择，工具箱包含本机密码管理。供应商、默认模型、人格和服务连接分别打开，所有子页与 Android 返回键均回到设置首页。

“检查更新”显示当前 App 版本，手动读取官方 Release 清单，REST API 作为备用；不要求连接知行服务，不发送服务令牌或个人记录，也不在后台轮询。检查期间阻止重复请求，结果复用底部弹层展示正式版本、下载与发布说明。没有安装包时说明发布尚未就绪；各来源的网络、限流和解析失败分别说明，不能显示成已是最新版。Android 在 App 内下载、显示进度并支持取消，核对安装包后交给系统确认覆盖安装；首次可能需允许安装应用，返回后可继续。安装器打开不表示安装成功。发布页作为用户主动打开的备用入口，保留用户当前资料。

模型供应商显示品牌、模型数与配置状态，可搜索、新增、编辑、停用和删除。底部弹层分“配置 / 模型”，支持远端模型列表批量添加、手动添加、编辑能力与三项连接测试。密钥仅提交至服务端，表单留空保留原值，清除是显式操作；不将已配置标成已连通。默认模型仍在单独入口选择。
搜索服务复用 `SearchPicker` 的管理模式，支持增删，添加成功留在服务列表；管理入口没有聊天搜索开关，添加时不改动当前选用的搜索服务。移除当前选用的服务后清除对应选择。

## 悬浮提示栏

根页面挂载一次 `NoticeProvider`，页面通过 `useNotice()` 的 `show` / `dismiss` 显示和移除提示。
提示悬浮在安全区域内，不改变页面布局；支持语义色、关闭、自动消失和可选操作。
同一 `id` 更新原提示，`duration: null` 可保留需要处理的状态。页面拥有的长期提示在离开页面时移除。
手机权限提示可直接携带“打开系统设置”操作；成功回执默认短暂显示。日历编辑器返回只说明已返回，不能表示日程已保存。

## 常用与最近、子页连续性

- 首页上半部依次为位置天气／日期、今日建议与草稿入口、下一项日程、财务／健康速览；其后保留用户固定的会话，下半部混排最近活动的会话与文件。位置天气栏与系统安全区间保留 `space.md` 留白，内容在单行或换行时均垂直居中。旧项目偏好保留在本机但不显示入口。打开已有内容只更新最近顺序，不复制内容或移动常用排序。常用偏好按服务地址保存在当前设备。
- 生活页包含财务与健康两张真实速览入口；未连接时显示对应入口卡，其他生活服务保留购物、出行与家居的普通聊天话题。施工页仅作功能待定占位。
- 财务和健康子页提供记录、设置与服务对话入口；服务对话与主聊天复用消息、输入和审批组件，关闭或 Android 返回可回到原服务页。搜索目标消息和来源页面在跳转时保留。
- 资源库使用单层紧凑列表；名称搜索由服务器完成，区分加载、失败、空库与无匹配。图片共享加载/失败/重试反馈，列表能回到来源会话；React Native 0.86 Android 的认证图片使用单元素 source 数组，保留 native 请求头。
- 旧通用计划入口已停用；健康提醒在健康子页按需设置。
- 任务详情默认展示 Markdown 结果和可下载文件，执行轨迹按需展开；授权与取消操作仍保持原有安全语义。

## 草稿与记忆纠错

- 欢迎页文本与发送选择按服务地址保存；恢复前锁住输入，读取或保存失败在输入区上方提供重试。会话与计划的草稿读取失败也支持原地恢复，不能用初始空值覆盖已保存的原请求。
- 财务与健康的未完成编辑用一次性悬浮提示提供“继续编辑”，不占概览页布局、不自动跳进表单；同一草稿跨页重进也不重复提醒，财务“手动补记”及健康记录入口仍可恢复内容。未改动的表单返回时不留草稿；已输入内容、旧版草稿和结果未确认的提交继续保留。
- 记忆列表采用共享字阶和分隔行，默认每行只显示“更多”按钮，展开纠正/忘记。搜索由服务器检索全库，分页失败保留已读内容与游标。
- 纠正在原条目内编辑；错误在编辑处显示，保存失败保留输入。Android 返回和侧栏遮罩共用未保存离开保护，提交中不能直接退出。原生 Modal 中的状态不依赖被覆盖的全局提示栏。
