# 对话布局与流式显示

主知行、财务助手和健康助手继续复用 `AgentChatHeader`、`ChatPanel`、`ConversationComposer`。模型、思考与联网搜索在一行横向滚动，输入区只保留附件、正文和发送。

页头“对话设置”收纳当前运行进度、取消、排队数与固定会话操作。有内容的本条草稿可在这里选择“接着处理”或“补充当前回复”；设置首页的“对话设置”管理这台手机的通用默认值。默认方式只用于新开始编辑的消息，已有草稿和未确认提交不被改写。补充目标已结束时明确提示并提供接着处理，不改绑另一条运行。批准和补充信息的卡片仍在消息区直接呈现。

后端在同一持久 LangGraph 执行中消费 values 与 messages 通道，将实际供应商正文与显式思考投影为可替换快照。运行重启／恢复先发送 reset，客户端按运行、流、消息标识和事件序号归并，避免重放重复或跨会话串流。工具沿用开始／完成／失败事件；不展示原始工具参数或结果。最终回答仍由原有 finish_run 唯一落库，快照不能替代最终回执。

客户端前台按游标读取事件，800ms 轮询、积压页100ms追赶；切到后台或离开会话会中止请求，恢复后继续读取。运行时收到的实际思考默认展开，可折叠；模型关闭思考或没有返回思考数据时，不编造思考链。最终消息到达后，流式正文撤下，思考与工具记录保留在该回复之前。

快照只包含显示所需文字，单字段最多64Ki UTF-16单位；每次运行时实例最多64个消息、512个快照和1MiB快照数据，超出后保留最终回答。内部总结、系统消息、工具结果和供应商签名不作为思考文字展示。接口见 [API](API.md)。

单元／图集成测试、JS打包、模拟器界面、真实供应商调用与生产部署是不同证据；本次实际验收回执单独保存，不以测试模型通过代替云端调用或手机运行。不创建新的正式版本标签，正式版0.2.2的附件保持原内容。
