# 安卓手机能力实际验收 · 2026-09-30

## 环境与证据

- Expo 57.0.25、React Native 0.86.3；Android API 36 ARM64 模拟器 `Expo_API_36`。
- Java 17、Android SDK 36，通过生成的原生项目运行 `assembleDebug`，364 个任务构建成功，APK 安装后实际运行。原生目录和 APK 不提交。
- 使用独立 debug APK `dev.zhixing.next`，JS 通过本机 Metro 加载最终源码；不是 Expo Go 验收。开发端口经 ADB reverse 连接。
- 系统日历用临时安装的 Etar 1.0.57 离线编辑器；原装 Google 日历要求账号登录，未使用个人账号。日历提供者中只建立合成验收日历。
- 计划列表及草稿使用仅监听本机的 HTTP UI fixture；它不执行任务、调用模型或接受业务写入，不代表后端或云端验收。
- 本机原始截图、APK 权限摘要和系统回执在 `Documents/Codex/acceptance/zhixing-android-permissions-20260930/`，未纳入仓库。

## 实际交互结果

| 场景 | 结果 |
| --- | --- |
| 未连接服务进入设置 → 手机能力 | 正常打开，只读取状态，没有自动弹权限框 |
| 通知首次拒绝、再次允许 | Android 权限框正常出现；拒绝后显示悬浮提示及设置入口，仍可重试 |
| 本机测试通知 | 系统通知栏实际收到“知行通知已就绪”及测试正文 |
| 单独关闭“知行通知”渠道 | 返回后显示渠道已关闭，阻止发送并提供设置入口 |
| 系统关闭全部通知 | Android 撤销权限并重启应用；重新进入显示未允许通知，允许操作可重新授权 |
| 日历编辑器取消 | 返回时只提示已返回，不声称已保存 |
| 没有日历处理程序 | 显示无法打开系统日历，操作按钮恢复可用 |
| 将重复计划的本次时间带入日历 | 标题和说明正确，2026-10-01 09:00 GMT+8；编辑器显示一次性事件 |
| 在日历中保存 | Calendar Provider 实际回执：`calendar_id=1`，标题“安卓权限验收：整理明天的资料”，`dtstart=dtend=1790816400000`，`rrule=NULL` |
| 定位首次拒绝、允许使用时访问 | 拒绝后显示提示；允许后同一次操作继续获取，没有把权限弹窗暂停误判成取消 |
| 单次定位成功 | 注入合成 GPS 31.2304 / 121.4737，实际返回 31.230398 / 121.473698、精度约 5 米及采集时间；取到后停止监听 |
| 带入对话 | 保留 `existing-draft`，追加位置文字；没有自动发送或创建新对话 |
| 手动取消与实际后台 | 均取消定位；系统 `dumpsys location` 的当前注册中不再包含知行 |
| 定位服务关闭、打开设置、返回 | 显示服务已关闭；设置入口打开 Location 页面，开启并返回后刷新状态 |
| 仅保留大概位置权限 | 不重复要求精确权限；本机没有可用网络定位结果，超时后按钮恢复、监听释放。未把此场景算作成功定位 |
| 深色、320 dp 窄屏、字体 1.3 | 卡片、文字和按钮正常换行、可滚动访问；浅色下也检查了结果与提示 |

通知拒绝提示出现前后，下方页面标题位置保持不变，提示绝对定位于安全区域内。
Android 通知 AppOps 注入不等同于真实系统总开关，此项诊断不计入通过记录。

## 权限、自动验证与边界

实际 APK 用 SDK `aapt2 dump permissions` 检查：包含通知、精确和大概前台位置权限；不含日历读写、后台定位、定位前台服务或精确闹钟权限。
日历读写与提醒权限属于外部日历应用，知行通过系统编辑器交给用户保存。

22 项针对性回归覆盖按需权限、拒绝和永久拒绝、渠道状态矛盾、定位新鲜度、非法坐标、首次结果与注册竞态、取消、超时、后台、权限弹窗返回及日历参数。
完整手机测试 61 项通过，typecheck、lint、Android / iOS JS bundle 通过。

GPS 使用模拟器合成位置，尚未验收实体手机的卫星或网络定位质量。模拟器注入没有被 Android 标为 mock，页面未编造模拟标记；逻辑测试另覆盖真实 `mocked=true` 的显示。
没有执行 iOS 原生构建或实机验收。当前 Android 基础能力不含服务器 push token 注册、FCM / Expo Push 投递、App 关闭后的任务结果通知、后台定位或日历自动同步。

验收完成后清除新安装的知行测试应用数据、合成日历和临时日历应用，恢复模拟器显示配置并停止本机验收服务。
