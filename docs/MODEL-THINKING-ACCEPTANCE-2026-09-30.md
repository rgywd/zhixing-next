# 模型思考与共享提示栏验收 · 2026-09-30

本轮验证搜索／思考透明按钮、按模型名称匹配思考档位，以及同步提示改用共享悬浮提示栏。接口、Worker、会话、工作目录均使用本机独立验收数据；云端仅通过临时回环代理调用已有 Qwen 配置，模型密钥留在服务器，没有修改生产会话或部署生产服务。

## 真实模型调用

真实 `qwen3.8-flash` 的关闭、低、中、极高、自动均返回 200。关闭发送 `enable_thinking=false`，三个深度档位发送 `enable_thinking=true` 与对应 `reasoning_effort`；自动省略两项参数。各档位不同时发送 `thinking_budget`。

首次验收发现原预算方案的高档请求返回 400；依据 [官方 Chat Completions 参数](https://docs.qwencloud.com/api-reference/chat/openai-chat)，将 Qwen3.8 Flash、2.4T、27B 纳入低／中／极高映射，保留固定思考模型不提供关闭的边界，再完成上述实调。

真实 LangChain 工具回合返回合计 54，并在续答请求中带回思考回执。真实 Deep Agents 文件任务创建 `thinking-acceptance.txt` 后读回；认证下载的 39 字节内容为“餐饮36元，交通18元，合计54元”，模型省略了提示末尾句号，金额与合计正确。两次工具续答带回的思考回执长度为 489 与 71；重新打开 SQLite 并通过图读取状态后，三条助手回执长度仍为 489、71、139，工具结果数量为 2。

## 悬浮提示与恢复

共享 `NoticeProvider` 与 `useNotice` 提供四种语义色、默认 4 秒的短提示、主动撤下的持续状态、按 ID 更新、操作按钮及关闭。同步状态复用同一入口；提示覆盖页面顶部，不占布局空间，提示栏之外仍能操作页面。

Android 故障注入实际结果：

- 短时 503 静默；持续 503 仅显示一条自动重连提示。提示前后页头触摸区域均为 `[32,149][147,265]`，草稿输入框均为 `[55,2040][1025,2183]`。
- 重新连接可触发后台读取；故障仍在时保留单条提示。关闭后继续轮询，同一故障没有反复弹出。
- 401 改为即时凭证提示；接口恢复后提示自动移除，同一份 `Draft-survives-reconnect` 草稿保留。
- 320dp、130% 系统字体、夜间主题下提示可完整换行，重连和关闭按钮可点；输入区仍无布局位移。关闭、系统返回首页、进入设置通过。系统密度变更重建 Expo 页面后，重新打开原会话仍能读回草稿。
