## 预验收发现与修复

早期真实运行暴露了三个问题：长提示词下表达偏好遵守不稳定；没有明确人物的代词会泛搜并枚举人物；新增同称谓人物后，旧聊天可能继续沿用旧的唯一映射。相应补充了靠近当前请求的表达偏好、模型菜单与执行层共同约束、实际读取依赖及会话失效。

表达偏好只投影到模型调用的消息副本：ID、图片块和 metadata 保留，数据库原文与 checkpoint 不改；只选择当前运行 accepted／applied 的真实用户消息，排除助手转送和内部消息。最新用户要求优先，表达偏好不授予权限。命名委派助手继续使用系统中的有界上下文，限定来源的研究助手不扩大来源。

独立诊断确认旧系统尾部提醒未在当前模型客户端转换为请求时丢失；并修复“用户的回答偏好是……”未进入核心筛选的措辞边界。初次合成输入“先结论，再用不超过三句解释”还存在总句数歧义，最终改为明确“整条回复包括结论总共不超过三句”，仍按总共至多三句检查；运行时保留用户原范围，不能把仅限制解释的偏好擅自加强为整条限制。

旧批次原答和失败结果保留。评估同时修正了未识别“是指谁”的澄清表达；混合算术场景明确要求使用工具后，才用实际工具回执验证独立操作仍可执行。最终整批重新运行，未将旧失败改写为通过。
