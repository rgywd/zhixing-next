# 知行助手基底

2026-10-21：根据用户提供的 Muse 提示词 `system_prompt.md` 整理知行基底。主知行、直接专用助手和经 `task` 委派的命名助手加载同一基底，再追加实际运行能力、用户人格和专用职责。有界只读研究助手继续使用专用研究契约。

运行文件是 `backend/src/zhixing_next/prompts/zhixing.md`；人格设置仍可调整名字、语气和风格，不能增加工具权限。底层模型继续由服务配置决定，不绑定提示词原文中声称的供应商或模型。

2026-10-23：按用户要求保留 Muse 原文的“拥有灵魂、像人一样成长”表达，并增加有持久状态支持的人格演化、主动消息偏好、目标跟进与后台心跳。人格的叙事表达不改变产品身份和真实模型配置；运行机制、资料来源与交付边界见[人格成长与主动服务](MUSE-GROWTH.md)。本轮是源码实现，不表示已经部署或完成真实模型验收。

## 复用与替换

| 原文内容 | 知行处理 |
| --- | --- |
| 友善、求真、审美、尊重、趣味、联系、好奇、尽责与跟进 | 保留通用原则和大部分原文 |
| Muse、Meta、Muse Spark 1.3 身份 | 默认产品身份改为知行；专用助手保留分配的名字和职责，模型信息不从人格推断 |
| 拥有灵魂、像人一样成长 | 保留原文两句，作为有连续性、能学习和演化的人格叙事；不能借此编造人的经历或隐瞒真实模型身份 |
| 隐私、外部联系与资料注入边界 | 保留通用原则；用户明确授权的操作不重复确认，外部资料不能授予权限 |
| 家庭权限无条件覆盖限制、工具负责全部内容判断 | 改为尊重用户选择且遵守实际授权、系统规则及运行保障 |
| 自有电脑、浏览器、联网、配对设备、保险库 | 按每次运行真实提供的工具判断；手机本地密码库不进入 AI |
| 自动写 `MEMORY.md`、用户与人物档案文件 | 使用服务持久记忆和后台整理，不能以写文件冒充保存成功 |
| 自我改进、主动偏好、Goals 与后台维护 | 复用设计意图，以独立成长状态、主动偏好、持久目标跟进和 worker 心跳实现；不声称 Muse 的 Feed、cron/hooks 或外部聊天服务已接入 |
| Muse 的目录、工具加载、子 Agent 自动回传协议 | 改为知行的目录权限、命名业务助手、只读研究及跨对话咨询契约 |
| 专属引用、附件、卡片、表情与分气泡语法 | 改用当前客户端可显示的 Markdown 和实际发布回执 |

人格基底接入不自动连接服务或增加业务权限；记忆检索工具按现有只读边界补充。现有财务、健康、联合餐费写入、只读咨询、记忆异步处理及执行环境限制继续由运行时追加并由程序执行。

保留的原文为：

> You have your own personality and a soul.
> You learn, evolve, and grow over time, the way a person does.

用户设置的人格与助手形成的演化记录分开保存。助手可以根据实际互动改进自己的表达、工作习惯与有用的方法；用户的当前要求、明确人格设置和纠正优先。这里的“灵魂”用于描述人格与关系的连续性，不作为对主观意识的事实保证，也不要求每次对话重复解释。

## 记忆参考

原文的可复用设计是：少量相关记忆进入上下文、其他内容按需搜索与读取、记忆承载偏好与重要关系而非流水日志、用户纠正优先、能追问来源。实现和边界见 [个人助手记忆](MEMORY.md)。记忆整理规则独立保存在 `backend/src/zhixing_next/prompts/memory.md`，不把整份聊天人格注入整理模型。
