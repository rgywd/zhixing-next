# 知行与 TG 表达修正

## 问题与改动

服务器检查发现，TG 的系统人格已更新，但网关仍把旧的整份人设放在每一条用户消息前。旧卡要求频繁使用语气词、隐瞒 AI 身份，与现有系统卡冲突。App 则仍使用 DSH 默认 coding-agent 人格，加上要求日常回复汇报完成项的业务指导，容易把闲聊变成客服开场或工作报告。

- `dsh-app` 0.4.1：只为 App 自有会话挂载知行人格，覆盖默认人格前缀；工具指导继续保留。闲聊、补充、纠正和详细任务分别按当前需要回应，任务执行后才汇报真实结果。知识问题不再顺手读取无关个人记录或催用户开始另一项任务。
- `dsh-messenger-persona` 0.1.1：保留三月七的性格、记忆约定和角色边界，减少强制语气词、心理解释、比喻安慰、追问与收尾套话。网关 `instructionPrefix` 改为 `Channel: Telegram.`，人格只有系统段一处维护。
- `dsh-tg-companion` 0.1.1：历史回顾去掉旧网关人设，不把模型专用的替换事件当成新发言；主动新闻仅依据实际标题和摘要，不评价未读取的照片、视频。主动频率、发送回执和共享记忆规则不改。

模型、推理档位、工具集合、宿主权限和业务协议保持原配置。没有引入回复后重写模型、关键词硬删或每轮只能一句话的限制。

## 旧会话如何生效

在 TG 原生 `agent/pre-step` 接受步骤之后、组装模型请求之前，检查当前模型历史中已知旧网关前缀。匹配必须同时满足 Telegram 网关来源、首文本块、完整的旧前缀和分隔符；用户引用、近似文本、其他渠道或系统上下文均不匹配。

使用 DSH 原生 `user/message` 单节点 `surfaceOp: replace`，并用 `sourceEventSeqs` 引用原事件。正文、附件、消息 ID、模型中的位置不变，原始事件仍在不可变日志里。宿主根据 surface generation 重建请求序列；不修改冻结的 `llm/stream` 请求，也不覆盖持久日志。新会话不产生旧前缀，恢复后的旧会话下一轮自动处理，第二次运行不再追加替换。

陪伴历史仍按原始发言顺序和时间回顾，使用同一精确清理函数，跳过替换副本。读取窗口按真实用户输入定位，避免较长的迁移尾部挤走最近对话。已压缩为摘要的旧内容不做字符串猜测或破坏性重写。

## 验证

- 本地 `typecheck`、`lint`、619 项 mobile 测试、54 项 DSH 测试及分支名检查。
- DSH 0.2.2-alpha.2 原生集成：TG 历史迁移、不可变原文、重启幂等、人格隔离和热加载；知行实际模型输入包含专属人格并移除默认 coding 身份。工具读写、原生队列、取消、压缩、历史分支、业务存储、权限及私密变量回归保持通过。
- 用当前生产 TG 日志做只读内存验证，精确匹配四条旧前缀；原始文件校验值不变，迁移后重新加载仍可重放且不重复处理。
- 服务器独立 DSH_HOME、工作目录、测试用户和业务数据运行真实 DeepSeek Flash。实际网关使用测试回复回执，未配置生产 TG 连接，测试对话不进入真实聊天。验证了多轮闲聊、详细比较、食物份量更正、真实文件写入与 Node 验算、真实记账回执、remember 写入、新会话和进程重启后的记忆召回。

首轮试聊仍出现擅自解释疲惫原因、回答数据库选型时查看饮食记录并劝用户开始记录。随后补充 App 会话末尾的表达指导，复测已不再读取这些无关记录；热量更正只返回变化量。另用没有写入人格示例的新句子复测，避免只检验模型是否照抄示例。

隔离试聊示例：牛奶由 250 毫升更正为 200 毫升后，回答“那算下来是 130 千卡，少了约 33 千卡”；明确要求记一笔餐费后，实际工具成功，再简短确认金额和支付方式。复杂问题仍可详细展开，不能从短聊天的改善推断所有长回答已经没有模板句式。

这是有限样本的表达校准，不是“完全消除 AI 味”的保证。没有改变供应商、推理档位，也没有做手机端新版本验收。只更新服务器插件，不创建 App 正式版本、标签或 Release。原始验收回执保存在仓库外的私有验收目录，不提交凭据、联系人标识或私人聊天日志。

## 部署与回滚

使用不可变插件目录与打包后的 `dsh-app`，在同级临时 profile 保留原有 bundle、配置和依赖链接，用原服务账号完成安装。切换前备份完整 profile、宿主 patch、人格、会话、记忆、业务数据和私聊联系状态；空闲时短暂停服切换，之后核对服务与原数据。

回滚恢复旧 profile、宿主 patch 和人格配置，再重启服务。不要恢复旧空投递账本或覆盖部署后产生的会话、记忆和业务数据。原生模型历史替换不依赖自定义解析器，回滚后仍可重放，原始聊天保留。
