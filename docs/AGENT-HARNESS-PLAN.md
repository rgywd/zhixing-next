# 主智能体可靠执行计划

基线：2026-09-30，`79bc0d1`（#6 已合并）。本轮聚焦通用助手的执行闭环，不以增加工具数量或编程能力作为完成标准。

## 执行顺序与交付条件

1. **运行可靠性**
   - [x] 模型瞬时错误分类、有限退避重试；取消和新指令可打断等待。
   - [x] 重复无进展工具调用保护、模型调用与 token 预算、实际用量回执。
   - [x] 上下文窗口可配置，压缩沿用 Deep Agents 的实际模型容量。
   - 验收：429/5xx 后继续；鉴权错误不重试；已完成写入不会因模型重试重放；循环与预算有明确停止原因。
2. **长任务交付闭环**
   - [x] 持久任务步骤、完成条件与验证证据；未完成步骤不能被静默宣称完成。
   - [x] 隔离环境中的后台进程启动、读取、等待和停止；超时、取消和重启都有真实状态。
   - [x] 必要问题可持久暂停，App 回答后从原步骤继续，取消后旧回答失效。
   - 验收：长任务中启动进程、做其他工作、检查退出结果；中途询问、重启、回答后交付；失败与未验证结果明确呈现。
3. **历史与外部服务**
   - [x] 主智能体检索历史对话与资源，保留来源定位和读取范围，支持分页读取。
   - [x] 优先接入用户指定的 GitLab：项目及议题检索、创建与更新议题；服务端凭据、项目范围、写操作批准、持久回执及恢复核对。通用 MCP 连接器留待有第二个实际服务需求时扩展。
   - 验收：跨对话找回已有信息；GitLab API 完成真实读取和受控写入链路；外部副作用不会在重启后无条件重复。第三方账号验收另记实际结果，不用本地接口回归冒充。
4. **可维护性与持续验收**
   - [x] 子助手可指定模型，权限仍按显式工具列表限制；共享预算和用量统计。
   - [x] 受控技能目录可扩展，实际挂载并被执行智能体读取。
   - [x] 关键场景回归集和 CI，包括恢复、副作用、询问、外部工具与交付验证。
   - 验收：最终提交通过后端、移动端及双平台 bundle 检查；Docker 集成回归单独运行并记录；原生和真实供应商验收如实区分。

## 实施边界

- 使用现有 SQLite、LangGraph checkpoint、操作日志和共享 UI，不另建调度平台。
- 不把完整任务自动重跑当成重试；只有尚未产生工具副作用的模型请求可自动重试。
- 任务步骤、用量、来源是内部执行依据，用户仅在必要问题或外部写操作时参与。
- token 用量以供应商返回为准；缺失标为未知，不推算成账单金额。
- 后台进程随隔离容器生命周期结束，恢复后核对中断状态，不假称仍在运行。
- 本轮不承诺 OAuth 全家桶、桌面控制、多租户或任意长期驻留服务。
