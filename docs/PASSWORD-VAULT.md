# 本机密码管理

入口为“设置 → 工具箱 → 密码管理”，未连接知行服务也能使用。首次设置独立主密码，之后每次进入解锁；主密码至少 12 个字符，保留输入的空格与大小写。主密码无法找回。当前只保存在这台设备，不随系统备份迁移；卸载会丢失密码库，请在录入前理解这一点。

## 使用范围

- 每条记录必须填写网站名称或网址、账号、密码；支持辅助邮箱、电话、多个密保问题和答案、备注及自定义字段。自定义字段默认按秘密隐藏。
- 列表按最近修改排列，搜索网站、账号、辅助邮箱和电话；不搜索密码、密保答案、备注及自定义字段内容。
- 支持新增、详情、编辑、删除、生成 20 位随机密码与修改主密码。密码、密保答案和秘密字段默认隐藏，需明确点击显示或复制。
- 编辑内容单独加密保留，不使用普通聊天草稿；保存失败留在原处，原记录仍保留。返回列表后可从次要文字入口继续未完成编辑。
- 离开密码库、切到后台或闲置两分钟后锁定；重新进入前台不会自动解锁。页面内的返回先收起键盘，再回列表，最后锁定并返回设置。

密码库没有 Agent 工具或上传接口，不进入 AI 对话、资源库、记忆及普通草稿。其他服务仍遵循 AI-first，密码资料使用独立本机操作。当前不提供同步、导入导出、密码恢复或系统自动填充。

## 存储与保护

主密码经系统 PBKDF2-HMAC-SHA256 派生 256 位密钥（600,000 次、随机 16 字节盐），使用 Expo SDK 57 的原生 AES-256-GCM 加密整份内容。每次写入使用新的 12 字节 nonce 和 16 字节认证标签，版本、派生参数和盐绑定为认证附加数据。外层文件仅包含版本、派生参数、盐和密文。主密码与派生密钥不持久保存。

Android 写入应用的 `noBackupFilesDir`，使用 `AtomicFile`；iOS 写入 Application Support 下的独立目录，标记不参与备份，使用原子写入和完整文件保护。原生写入核对上一份密文后提交，读取失败、损坏、解密失败及写入冲突均保留原文件，不以空密码库替换。Android 密码库要求 API 26 起；应用其他功能仍支持原有的 API 24 起。

进入页面前启用系统截屏／录屏保护；iOS 另外启用应用切换器遮挡。保护不可用时不打开密码库。原生配置排除该依赖附带的图片读取权限；Android 14 起保留其初始化必需的系统普通截屏检测权限，不产生运行时授权弹窗，页面不收集截屏事件。Android 复制标记为敏感内容，iOS 使用仅本机且 30 秒到期的剪贴板。复制后切到其他 App 时，密码库立即锁定，复制内容保留原有短时粘贴窗口，不重新计时；回到前台、手动锁定、离开密码页或计时到期时尝试清理本应用仍持有的内容，不能清除后来由其他应用复制的内容。系统后台限制可能延迟清理，因此界面不承诺绝对的 30 秒清空。

相关原生实现位于 `modules/zhixing-vault`，由 Expo 本地模块自动链接；`android/`、`ios/` 仍由 Expo 生成。必须重建独立原生包，Expo Go 不包含此模块。

## 验证边界

定向回归覆盖密文格式与认证、Unicode 主密码、必填字段与秘密精确保留、CRUD 和失败保留、加密草稿、并发写入、锁定取消、AppState／卸载生命周期、页面返回与屏幕保护串行化。标准 Node 加密实现用于交叉检查，不代替手机原生桥接验收。Android 模拟器验收与安装包回执保存于本次交付记录；实体手机及原生 iOS 未验收。此功能不改变既有 0.2.1 正式 Release 的附件。

原生 API 依据：[Expo Crypto](https://docs.expo.dev/versions/v57.0.0/sdk/crypto/)、[ScreenCapture](https://docs.expo.dev/versions/v57.0.0/sdk/screen-capture/)、[Android KDF 支持](https://developer.android.com/reference/javax/crypto/SecretKeyFactory)、[Android 敏感剪贴板](https://developer.android.com/develop/ui/views/touch-and-input/copy-paste#sensitive-content)。
