# 本机缓存与同步

客户端先显示本机已有内容，再在前台使用期间同步服务器；短暂断网不清空页面。此变更基于 0.2.9 主线，尚未正式发布。

## 已实现

- SQLite 持久保存会话列表、助手与模型配置、近期资源索引、已读取的聊天正文和附件索引。翻过的历史消息一并保存，重启后无需联网也能查看。
- 会话列表和聊天先恢复本机副本，再进行网络读取。列表的各接口分别接受结果，一个接口失败不丢弃其他已成功的更新。
- 聊天从上次完整读取的位置补消息，继续翻页直到追上最新状态；发送回执单独合并，不能把读游标跳到尚未同步的位置。已接受消息仍会更新最终处理状态。
- 首页按当地日期恢复财务摘要和健康记录，后台更新失败保留上次结果。健康页复用相同摘要；财务完整页面另存摘要和流水，成功读取时同时更新首页摘要，避免混用两种结构。
- 天气、位置和当日日程作为较小的手机快照保存。启动先检查原有开关和当前系统权限，昨日快照不用于今日；天气继续按观测时间校验。权限撤回或关闭相应能力时移除对应快照内容。
- 进入后台停止聊天轮询工作，返回前台继续刷新；不增加安卓常驻服务或后台定时任务。

## 数据边界

服务读取缓存使用服务地址与令牌的 SHA-256 摘要隔离，SQLite 不保存令牌。切换服务或令牌后重新读取该身份的数据；旧版仅按地址保存的服务摘要不迁移，避免无法确认归属的资料混入新身份。连接令牌继续由 SecureStore 保存。

缓存保存的是曾成功读取的服务器内容。未读取过的历史、图片和文件二进制不会自动全量下载；本次没有增加离线发送或自动重放业务修改。原有草稿、照片上传和请求回执机制继续负责未提交内容。运行中状态与服务在线状态每次重新核实，不从缓存声称任务仍在运行。

财务摘要按月份分开，同一个月内可继续读取已有预算；健康摘要按记录日期分开，不把昨天的餐次当成今天。旧请求的迟到结果不能覆盖同一键上更新的快照。缓存读取失败或损坏会退回网络读取，不阻断在线使用，也不覆盖原有未提交草稿。

## 验证

移动端回归覆盖 SQLite 文件关闭重开、大于 Android 常见 KV 单条读取限制的聊天内容、连接身份隔离、迟到写入、损坏缓存、离线冷启动、历史翻页、跨多页补消息、发送回执不跳读、日期变化、手机权限撤回以及缓存迟到不覆盖新结果。

- `npm run typecheck`、`npm run lint`、`npm run test:mobile`（531 项）、Android / iOS JS bundle 与分支命名检查均通过，属于本地检查。
