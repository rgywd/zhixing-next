## 验收发现并修复的问题

1. **LibreOffice 默认配置目录不可用**：容器以宿主 UID 运行，没有普通 Linux 用户配置目录。模型先尝试默认配置和修改 HOME，均以退出码 77 失败。显式指定 `-env:UserInstallation=file:///tmp/lo-calc` 后重算成功。内置 spreadsheets 技能现包含可写 profile、独立输出目录、公式与缓存两次读取检查；真实 Docker 回归覆盖生成、转换与读回实际缓存。
2. **成功回执遗漏批准事实**：原件替换确实等待了手机批准，但模型随后误称“工具没有要求额外批准”。文件成功及恢复核对回执现包含持久批准记录的状态、ID 和决定时间；无须逐次批准的写入明确标识 `required=false`。修复后的真实 Qwen 复验正确引用批准状态和时间。随后发现它把 `backup_available` 理解为 App 有版本历史入口，回执进一步说明备份只支持服务端人工核查与恢复。集成测试检查恢复后的真实工具消息，避免只验证接口成功。

补充备份说明后的独立真实 Qwen 任务再次通过：原件获批后只发生“周五→周日”替换，模型明确说明 App 无版本历史或一键恢复入口，并区分服务端人工恢复与再次获批改回文件。此补充复验通过认证 API 提交批准，前两次原件修改的批准通过 Android 界面完成。
