# 日夜主题验收 · 2026-09-29

本次主题升级覆盖全 App，配色与开发约定见 [UI.md](UI.md)。白天使用白、朱红与金色，少量功能使用冷蓝；夜间参考 Grok 的近黑、炭灰层次，加入暗金与卡其。模型品牌保持原色，Qwen 深色渐变在夜间增加中性衬底。

## 自动验证

- `npm run typecheck`、`npm run lint`。
- `npm run test:mobile`：25 项通过。主题回归覆盖保存与恢复、跟随系统、明确选择优先于迟到读取、快速切换写入顺序、损坏偏好、存储失败、正文与控件对比度、共享组件重绘和 Markdown 代码高亮。
- `npm run bundle:android`、`npm run bundle:ios`。
- 两套主题的正文、辅助信息与填充按钮的有效配色检查达到 4.5:1 对比度；禁用态、装饰线与供应商原始标志不包含在该声明中。

## Android 原生交互

Android API 36 ARM64、Expo Go 57.0.9；使用本地合成数据服务，没有调用供应商或修改云端资料。

| 场景 | 实际结果 |
| --- | --- |
| 手动切换 | 白天、夜间即时更新当前页面、状态栏、输入框和已打开的底部弹层 |
| 草稿 | 在首次对话填入建议文字，切换日夜后文字和当前页面保留 |
| 持久化 | 强制停止并重新打开 Expo Go 后恢复夜间偏好 |
| 跟随系统 | 选择跟随系统，再切换 Android 深浅模式，工具箱即时改变配色，偏好仍为跟随系统 |
| 页面 | 首页、生活、财务、工作、工具箱与主聊天均检查；夜间无浅色插画底面 |
| 选择器 | 模型列表、搜索服务、思考档位和外观弹层检查；品牌、选中状态与文字可读 |
| 输入 | 创建项目表单在键盘上方，文字、光标及主按钮可读；没有提交测试项目 |
| 窄屏 | 320dp、130% 字体，三项主题选择和聊天工具栏完整可操作 |

## 验收边界

本轮没有生成独立 APK、构建 iOS 原生包或运行真机。新增 `expo-system-ui`，已有 development build 需重建，JS bundle 成功不能替代原生构建验收。Android 输入法外观由输入法与设备设置控制，App 不覆盖系统键盘配色。
